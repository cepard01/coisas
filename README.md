# coisas

`coisas` is a shared storage repository for miscellaneous files, projects,
experiments, references, and other materials that may be useful to keep
together without creating a separate repository for every item.

The repository is intentionally flexible. Content can be added in its own
directory, and AI agents or other tools can inspect the repository as a
single source of context when needed.

## Current contents

- `daisysite/` contains the DaisySite workspace and its related assets.

## Guidelines

- Keep unrelated materials in separate, clearly named directories.
- Do not commit secrets, credentials, private keys, or personal data.
- Use `.env.example` files for configuration templates instead of committing
  real environment files.
- Add a short README inside larger directories when their purpose is not
  obvious.
